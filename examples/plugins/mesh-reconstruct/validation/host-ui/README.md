# Actual-host UI acceptance probe

This test-only standalone crate consumes the published command host at an immutable Git revision. It starts no TCP server and adds no runtime implementation or firewall exception. The native root SDK and independent guest tests are separate gates.

Set MESH_RECONSTRUCT_PACKAGE to the exact verified component folder and MESH_PUBLIC_INPUT to the independently generated public Bracket.stl, then run this manifest with the ci profile and one test thread. The owning runner must record source/toolchain/lock/input/module and result/executable hashes and use an independent physical local target under fresh resource admission.

The probe observes real background work, resolves and clicks the actual Stop widget, checks that no source or history change is adopted during later frames, and verifies the following command is accepted. A run that never observes work cannot be reported as a cancellation pass. This is an actual-component acceptance observation; the host's deterministic cancellation regressions remain required.

Cargo.lock preserves the registry versions/checksums from the published host's lock. All patched host crates use the same Git revision. No private input or screenshot is included.
