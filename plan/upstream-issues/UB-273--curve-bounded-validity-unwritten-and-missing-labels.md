#### UB-273. Curve-bounded surface validity reads unwritten continuity or past its report labels

- **Severity:** Crash / undefined behaviour
- **Area:** Surface validity diagnostics
- **Location:** `source/SMLib/src/SmCurveBoundedSurface.cpp:551` (`SmCurveBoundedSurface::AssertValid`); `SmSurface.cpp:6168`, `:12361`, `:34878`; `SmAssertArray.cpp:42`, `:317` at pin `3fd5b9548d19aa8c12c29bc9637a96d42a06f8a5`.
- **What happens:** At levels 0..2 the curve-bounded override calls `SmSurface::AssertValid`. Its continuity predicate ignores `CalculateContinuities` failures and reads the minima. Curve-bounded surfaces inherit the generic `GetKnots`, which clears the knot array and fails; `CalculateContinuities` exits before writing its minimum. Separately, the override declares `sAssertCurveBoundedSurface_list` with six entries, but `SM_GetAssertLabelList` does not dispatch this class and returns the one-entry default table. Failed test 0 therefore has the default Unknown_Assert label; a failed boundary/context test 1..5 with a report list indexes past that table.
- **Trigger:** Any curve-bounded surface checked at a non-GIVEN level reaches the unwritten-continuity path. At `SM_LEVEL_GIVEN`, an invalid boundary-curve owner plus a non-null report list reaches failed test 1 or 2. A null report list avoids label construction; those boundary failures are defined and return false.
- **How found:** Implementing the remaining WP3b override in #1621; targeted Rust tests first exposed the existing guard for an unwritten continuity output, then a pinned-source audit identified both native paths.
- **Confirmed:** source-identified undefined reads; guarded native execution now completed. The shim probes initialized continuity outputs and rejects the early empty-array failures. Defined LEVEL_GIVEN basis reports and null-list boundary failures compare successfully against native; invalid-owner boundary reports with a list are guarded. The unsafe reads themselves were not deliberately executed, so no native crash confirmation is claimed.
- **Rust port:** Preserve the generic continuity failure as `InvalidInput`, the defined default label for test 0, and false boundary results with no report list. Out-of-range label requests return `InvalidInput`. No replacement label table or tolerance change is introduced.
