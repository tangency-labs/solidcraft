#### WR-598. `DeleteTopologicalVertex` dereferences a null `SmBSplineCurve` cast of an edge's `SmCrvOnSurf`
- **Severity:** Crash / undefined behaviour
- **Area:** Topology
- **Location:** `source/SMLib/src/SmBrep.cpp:7773`-`:7783`, `SmBrep::DeleteTopologicalVertex` (v1.0.1, 3fd5b95).
- **What happens:** to join the two edges at the vertex, upstream copies both edge curves, casts each copy with `SM_CAST_PTR(SmBSplineCurve, pCopy)` and calls `Trim` through the result unchecked. An edge curve that is not an `SmBSplineCurve` kind (an `SmCrvOnSurf`, an `SmProjectedCurve`, ...) gives a null pointer and a segfault (the copy also leaks). Where the curve is a curve on a B-spline surface along a UV line of constant u or v, the edges are the same curve as that surface's iso curve and could be joined.
- **Trigger:** the SolidCraft fork's boolean post-process of a union whose full-turn cylinder face has its seam run on through a covered face: the seam is two edges, a new `SmLine` and the extrusion's `SmCrvOnSurf` iso line, and `BooleanPostProcess` removes the vertex between them (tangency-labs/smlib@829b982, segfault at `SmBrep.cpp:7826` in gdb on the fork). Minimal: two wire edges, an `SmLine` from (0,0,0) to (0,0,1) and an `SmCrvOnSurf` from (0.5,0) to (0.5,1) on the bilinear patch (-1,0,1), (1,0,1), (-1,0,2), (1,0,2), glued at (0,0,1); `DeleteTopologicalVertex` of that vertex with either edge.
- **How found:** crash in the C++ reference run (a standalone program against the pinned reference libraries, built with the harness flags).
- **Confirmed:** yes. The minimal input above segfaults in the pinned C++ (exit 139) whichever edge is deleted.

Rust: the port never dereferenced the cast; it returned `SM_ERR` after the join failed, the vertex left in place. It now returns that silent `SM_ERR` before trimming any copy for a curve that is not of an `SmBSplineCurve` kind (unconditional; the fork's crash avoidance). The fork's join of a curve on a B-spline-kind surface along a constant-u or constant-v UV line, as that surface's iso curve over the edge (`sm_ExactBSplineOfEdge`), is opt-in: `Kernel::fixes.delete_vertex_joins_seam_iso_curve`. Regression test: `crates/solidcore/tests/wr598_delete_vertex_seam_iso_curve.rs` (flag on and off).
