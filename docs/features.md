# Features

SolidCraft's commands by area, generated by `cargo xtask features` from the command registry (`solidcraft-cli commands`). Planned commands are marked in their rows. Every command runs the same way from the toolbar, a script, `solidcraft-cli exec <id> '<json>'`, the control channel and MCP; parameters are in the [command reference](book/src/reference/commands.md) (`cargo xtask book`). Status and plans: [ROADMAP](../ROADMAP.md).
