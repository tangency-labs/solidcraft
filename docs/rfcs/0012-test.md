## Summary

Simulation is not truth. Close the loop with a test plan tied to requirements, fixtures and
instrumentation, captured measurements, a comparison with the simulation, and a defect/regression
record. This is what makes the next iteration informed instead of folklore.

## Scope

- Test plan per requirement: method, fixture, pass/fail, sample size.
- Fixtures and instrumentation: jigs designed in CAD, probe points, test hooks.
- Measurement capture: serial/logic/scope data, photos, caliper and scale readings; import and link.
- Simulation vs measurement: compare, explain differences, update models.
- Defects, root cause and corrective action.
- Regression and retest after a change.
- An optional test review.

## Four surfaces

Every command ships in the GUI, CLI, MCP server and documentation. Measurement import and
sim-vs-test comparison must be scriptable, because repeated tests are the point.

## Readiness (optional)

Every must requirement tested; differences from simulation explained; open defects owned.
