SolidCraft's journey from a mental idea to a physical product, documented as a map rather than

## The rule

Every tool is available on its own and every step is skippable. The map is documentation and an
optional in-app guide, not a state machine:

- No phase is required.
- No tool is a prerequisite for another.
- Save, export, simulate, prototype, fab output and release are never blocked by a missing step.
- Readiness reports suggest; they never enforce.
- "Not now" is a complete answer.

Every tool ships from the **GUI, CLI, MCP server and documentation**, with the same schema and tests.
That is about implementation completeness, not about the user's process.

The journey is a loop. Prototyping early, skipping Intent, or going straight to a final model are
all normal ways to work.
