# Brand assets

- `logo.svg`: the mark (an isometric solid with one filleted edge and a NURBS curve with
  its control polygon on the top face). Generated geometry; edit freely.
- `og-image.png` (1200x630): social preview. Source `og-image.html`; regenerate with
  `google-chrome --headless=new --hide-scrollbars --virtual-time-budget=5000 --window-size=1200,630 --screenshot=og-image.png og-image.html`.
  GitHub does not read this file automatically: upload it under Settings > General >
  Social preview.

Do not use NVIDIA or SMLib names or marks as branding (no trademark grant).
