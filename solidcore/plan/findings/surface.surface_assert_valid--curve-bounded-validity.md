# surface.surface_assert_valid: curve-bounded validity and contained identities (2026-10-29)

Unit: `surface.surface_assert_valid`; owned override: `SmCurveBoundedSurface::AssertValid` (`surface.curve_bounded_surface`). Claim: #1621, based on main `d892c36a32`.

The complete override calls the inherited surface check unless LEVEL_GIVEN, validates the owned basis, then each 3D boundary and each UV boundary in their native order, with the intervening context reports. Rust's single supplied kernel makes the context tests intrinsic. The existing virtual curve validator is shared through a crate-only wrapper; derived curve checks are not replaced by the Curve base check. Boundary validation uses exact evaluation copies, so their lazy NURB mutations are not retained by the const surface call.

Contained reports need distinct identities: assigning every nested object the surface key would deduplicate separate failures. The default Surface API assigns keys by traversal ordinal after the caller's root key (wrapping). Callers accumulating independent checks must reserve those ranges or use the new `assert_valid_with_keys` callback. The callback also makes repeated object identities explicit; duplicate keys within one walk are rejected. No address hashing is used. Tests cover three nested failing bases and accumulated independent roots, including a root key of u64::MAX. The explicit validity depth counter is bounded by the shared MAX_GEOMETRY_NESTING (32); constructors already bound owned geometry at that depth.

The pinned native implementation has two undefined paths, recorded in `plan/upstream-issues/UB-273--curve-bounded-validity-unwritten-and-missing-labels.md`: non-GIVEN base checks read unwritten continuity minima, and failed boundary reports index an omitted label table. LEVEL_GIVEN and null-list cases exercise the defined override. The intended six-entry table is not installed in Rust: defined failed test 0 keeps the pinned default label. No native success is claimed for an undefined path.

The new fixture family has 128 named cases plus a separate 400-case `cbd` generated stream. The existing `gen` and `ext` stream generation is unchanged. Native objects are real CurveBoundedSurface wrappers, plane bases and CompositeCurve boundaries containing degree-1 B-splines; report identities, all report fields/text, the return value and last_add use the existing output format. Context-mismatch objects cannot be represented in the single-kernel Rust model. Other curve kinds remain handled by the shared virtual dispatcher; its existing unported derived overrides still propagate Unported rather than fake a result.
