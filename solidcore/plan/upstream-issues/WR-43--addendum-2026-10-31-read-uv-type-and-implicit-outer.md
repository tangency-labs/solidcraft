#### WR-43 (update, 2026-10-31). Opt-in UV boundary type dispatch and implicit-outer flag in `SmCurveBoundedSurface::ReadFromDB`

- **Location:** `source/SMLib/src/SmCurveBoundedSurface.cpp:709`-`778` (`SmCurveBoundedSurface::ReadFromDB`, specifically `:729`-`740`, `:764`-`772`, and `:775`) vs `SmCurveBoundedSurface::WriteToDB` (`:655`-`702`).
- **Defect:** `WriteToDB` serializes `m_v3DBoundaries.GetSize()`, `m_vUVBoundaries.GetSize()`, and `m_bImplicitOuter` (`:664`-`675`), the basis surface (`:678`-`680`), each 3D boundary curve with its `(type, dim)` header (`:684`-`689`), and each UV boundary curve with its own `(type, dim)` header (`:692`-`697`). `ReadFromDB` reads `bImplicitOuter` (`:733`, `:739`) and reads each UV boundary's `(lUVType, lUVDim)` header (`:767`), but:
  1. Calls `SmCurve::ReadFromDB(l3DType, rDB, lUVDim, ...)` (`:768`) instead of passing `lUVType`. When `l3DBoundariesSize == 0`, `l3DType` stays `0` (`:746`) and every UV boundary read fails with `SM_ERR`; when the 3D and UV boundary curve types differ (e.g. a 3D `SmBSplineCurve` with a 2D `SmLine` UV boundary or vice versa), `ReadFromDB` dispatches the wrong curve reader, either failing or returning a corrupted curve.
  2. Constructs `new (crContext) SmCurveBoundedSurface(*pBasisSurface, &s3DCurves, &sUVCurves)` (`:775`), omitting the fourth constructor argument `bImplicitOuter` (whose default in `SmCurveBoundedSurface.h` is `FALSE`), silently discarding `bImplicitOuter = TRUE`.
- **Fix (`Kernel::fixes.curve_bounded_surface_read_uv_type_and_implicit_outer`, #2164):** Default `false` preserves pinned v1.0.1 C++ behaviour in `CurveBoundedSurface::read_from_db` (including `surface.curve_bounded_surface` difftest parity). When `true`, `CurveBoundedSurface::read_from_db` dispatches each UV boundary curve with `Curve::read_from_db(k, luv_type, db, luv_dim, version)` and passes the stream's `implicit_outer` boolean to `CurveBoundedSurface::new`. `CurveBoundedSurface::write_to_db` is also ported so `CurveBoundedSurface` records round-trip in both `FileType::Ascii` and `FileType::Binary`.
- **Wired callers:** `Surface::read_from_db` (`surface::surface::p2`) and every polymorphic surface reader that delegates through it (`topology::brep_data`, `CrvOnSurf::read_from_db`, `IsoCurve::read_from_db`, `OffsetSurface::read_from_db`, `SrfInVolume::read_from_db`, `StepSurface::read_from_db`, and nested `CurveBoundedSurface::read_from_db`) forward `k: &Kernel` to `CurveBoundedSurface::read_from_db`.
- **Regression tests (`surface::curve_bounded_surface::tests`):**
  - `wr43_uv_only_and_implicit_outer_round_trip_ascii_and_binary`: serializes `CurveBoundedSurface` instances with `0` 3D boundaries, a 2D `Line` or 2D quadratic `BSplineCurve` UV boundary, and `implicit_outer = true` in both `FileType::Ascii` and `FileType::Binary` (database versions `30` and `42`); verifies default `Kernel` fails (`l3d_type == 0`), while `curve_bounded_surface_read_uv_type_and_implicit_outer = true` round-trips both `CurveBoundedSurface::read_from_db` and polymorphic `Surface::read_from_db` with `0` 3D boundaries, `1` 2D UV boundary of matching curve kind and evaluated points, and `implicit_outer() == true`.
  - `wr43_mismatched_3d_and_uv_curve_types_and_implicit_false`: tests both 3D `BSplineCurve` + 2D `Line` and 3D `Line` + 2D quadratic `BSplineCurve` with `implicit_outer` in `[true, false]` across `FileType::Ascii` and `FileType::Binary`; verifies default `Kernel` fails or misreads the UV curve as `Line::TYPE` (3D) and forces `implicit_outer() == false`, whereas opting in round-trips exact curve kinds, dimensions, evaluated points, and `implicit_outer()`, plus verifies `UpstreamFixes::flag_mut` and `UpstreamFixes::flags`.
