- **Details:** In `N_KnotVectorIsValid` (`source/SMLib/src/NL_BasisBasic.cpp:172-232`), the start-clamp loop (`:181-190`) requires `i == p` equal leading knots and the end-clamp loop (`:192-201`) requires `m - i == p` equal trailing knots, without checking that the two `(p + 1)`-knot clamps are disjoint (`m >= 2 * p + 1`) or span a positive domain (`U[0] < U[m]`). When `m == p` and all `p + 1` knots are equal (or `m == 0` with `p == 0`, including `[NaN]`), both end loops stop after `p` steps and the internal-knot loop (`is = p; ie = p + 1; while (ie <= m - p)`) never executes because `p + 1 > 0`, returning `0` (`Ok(())`) on a zero-span vector that `N_BasisFindSpan` and `N_BasisEval` cannot index (`UB-8`). Conversely, on the final iteration `ie == m - p` of that loop (`U[m - p]`, the first knot of the end clamp rather than an internal knot), `while (ie < m - p && ...)` does not advance `ie`, leaving `ie - i + 1 == 1`; line `:221` (`if ((ie - i + 1) > p)`) is then `1 > 0` for `p == 0`, rejecting valid single-span degree-`0` vectors such as `[0.0, 1.0]`.
- **Rust port (#2162):** Default (`Kernel::fixes.knot_vector_valid_requires_span == false`, `KnotVector::validate`, `nurbs::srf_basic::Surface::is_valid`) preserves pinned C++ v1.0.1 parity. With `Kernel::fixes.knot_vector_valid_requires_span = true` (`KnotVector::validate_with_kernel`, `KnotVector::validate_opt_in(p, true)`, `nurbs::srf_basic::Surface::is_valid_with_kernel`), validation requires `m >= 2 * p + 1` (checked without overflow) and `U[0] < U[m]` (rejecting `(p + 1)`-knot degenerate and `NaN`-end vectors with `NlibCode::Knot`), and checks `ie - i + 1 > p` only on interior knots (`i < m - p`, allowing single-span degree-`0` vectors such as `[0.0, 1.0]` with no interior knots while still rejecting interior knots of multiplicity `> p`).
