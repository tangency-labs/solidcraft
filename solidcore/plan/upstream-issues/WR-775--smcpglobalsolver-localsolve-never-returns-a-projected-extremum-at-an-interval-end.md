#### WR-775. `SmCPGlobalSolver::LocalSolve` never returns a projected minimum or maximum that lies at an end of the interval
- **Severity:** Wrong result
- **Area:** Geometry queries
- **Location:** `source/SMLib/src/SmCurve.cpp:11290` and `:11351`, `SmCPGlobalSolver::LocalSolve` (def. `:10951`).
- **What happens:** For `SM_SO_PROJECTED_MINIMIZE` and `SM_SO_PROJECTED_MAXIMIZE` each guess is solved by `LocalPropertyAnalysis`, which finds parameters where the projected distance is stationary. The branch at `:11290` means to save a span's start or end point when a later guess finds no root, but it leaves `bFoundSolution` false. The test at `:11351` returns from the span as soon as the first guess finds no root, and the later `if (!bFoundSolution) continue` skips the save for every other guess. An end of the interval where the distance is still falling (rising) is no stationary point, so it is never returned. A point whose nearest (farthest) projected point is that end gets an empty success, or, when the curve has a stationary point elsewhere, that point is returned although the end is nearer (farther).
- **Trigger:** a projected minimum of the point (2, 0.5, 0) along Z onto the segment from (-1, 0, 0) to (1, 0, 0): the nearest point is the end (1, 0, 0) at distance sqrt(1.25), and the solve returns no solution. Over the goldens' 7109 projected point/curve solves on main `a5a698c96`, 335 solves without a target distance return nothing and 22 return a point that dense sampling (4001 samples) beats (tangency-labs/solidcraft#13658, #13677).
- **How found:** tracing tangency-labs/solidcraft#13658 (vertices of a shell against a bounded line: 5 of 12 vertices had no answer).
- **Confirmed:** by reading the C++ (the two tests above) and on the port, which followed it. Solidcore now adds the end of the solver's interval as a solution when the projected distance grows (shrinks) from it into the interval (`curve::curve::p1`, tests `projected_extremum_at_an_end_of_the_interval_is_a_solution` and `projected_maximum_of_a_straight_spline_is_at_its_ends`). `sm_FindSideOfCurve` keeps its failure for a point beyond the end of the curve.
