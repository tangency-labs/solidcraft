Updates: WR-84

#### WR-84 (update, 2026-11-22). `edgeuse_convexity_propagates_step_off_failure` is removed; an edge use outside a loop has no sector

`topology::edgeuse::p2::is_convex_radial_sector` now always propagates an `evaluate_binormal_step_off` error on the edge use or its radial partner; upstream's `SER` in an `SmBoolean` function returns the status as `TRUE`. Removed: the field `UpstreamFixes::edgeuse_convexity_propagates_step_off_failure`, its doc file, the default path that answered `Ok(true)` (`ser_as_true`), the test of the flag's default and lookup (`wr84_flag_default_off_and_lookup_by_name`), the default-mode halves of the other `wr84_*` tests, and the flag from the name lists of `tests/issue_18166_g2_round_cut_by_carried_body.rs` and `tests/issue_2260_gn_pipe_refined_range_end.rs`. `num_samples == 0` still evaluates nothing and returns `true` for any edge use.

**An edge use outside a loop.** `EvaluateBinormal` refuses an edge use whose owner is not a loop use with `SM_ERR_INVALID_INPUT` (1007, "only an edge use in a loop has a binormal"). Such an edge use bounds no face, so it has no radial sector: every caller reads "convex" as "the wedge of material between the edge's two faces opens less than half a turn" and chooses a construction from it (side faces added or trimmed, the rollover side, wall foot or cliff edge, crossing an edge, offsetting or skipping the sector), and none has a branch where `true` means "no faces". The refusal is the existing typed error; no check or error was added.
