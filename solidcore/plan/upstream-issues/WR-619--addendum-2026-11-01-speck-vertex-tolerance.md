Updates: WR-619

#### WR-619 (update, 2026-11-01). Final vertices of skipped collapsed specks cover the speck's span in `ImprintIntersections`
- **What changed:** when `Kernel::fixes.imprint_skips_collapsed_definition` skips a collapsed speck definition on `(start_vtx1, start_vtx2)` (`ProtoTopologyManager::imprint_edge_definition` in `crates/solidcore/src/topology/proto_topology/p2.rs`), the manager records each vertex's maximum sampled distance to the speck along with the speck's endpoints, and `TopologyIntersector::imprint_intersections_reporting_edits` (`crates/solidcore/src/boolean/topology_intersector/p1.rs`, right after WR-306's edge-interval fit and before `GlueCoincidentBrepVertices`) grows each live vertex's tolerance (`update_only_if_larger = true`) to `zone_tol3d(k, 2 * gap_gain(k) * gap)`, where `gap` covers both the imprint-time speck distance and the post-WR-306 vertex distance to the speck's ends.
- **Why:** `collapsed_beside_sibling` tests the speck against the full vertex and definition tolerances (`1e-5` at `d = 1e-5`), whereas `SmBrep::ValidateAndUpdateTolerances` (`CheckLevel::Level2`, tests 0-3) requires every incident edge end to lie within **half** the vertex tolerance (`tol / 2`). Once WR-614 (`boolean_coincident_strip_drops_crossing`) lets the `d = 1e-5` union complete, `B`'s vertical corner edge survives attached to the merged vertex at distance `1e-5` (`7.5e-6` with WR-306's shift), which exceeded `tol / 2` (`9.95e-6` without WR-306, `6.25e-6` with WR-306). Growing only the vertex tolerance (without calling `UpdateVertexEdgeIntervals`, so 3D edge intervals and UV trims stay untouched) clears all four `Level2` vertex/edge checks while leaving `d = 1.5e-5` (not skipped) unchanged.
