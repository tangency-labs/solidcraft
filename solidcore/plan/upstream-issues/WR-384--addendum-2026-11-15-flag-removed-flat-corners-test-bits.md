Updates: WR-384

#### WR-384 (update, 2026-11-15). `flat_corners_test_bits` is removed

The fix is the default and its flag is gone (tangency-labs/solidcraft#14246, batch surface1). `Surface::flat_corners` (`surface/surface/p7.rs`) always tests each corner bit (`rtn & bit`) while it fills the corner points, so the flags it returns with the points are the flags it returns without them. Upstream's `if (lRtn &= bit)` keeps at most the first corner's bit and then clears it at the next test, so with the points wanted it returns 0 for every surface. Removed: the field `UpstreamFixes::flat_corners_test_bits`, SolidCraft's preset line, its entries in `fixes.json` and `issue_2260`'s list, the test settings in four SolidCraft-profile tests (`issue_1476`, `issue_1818`, `issue_1945_fork_1207_step4`, `issue_1950`), and the upstream-path assertion of `issue_525_flat_corners_keep_their_bits`.

- **Tests:** `issue_525_flat_corners_keep_their_bits` and the other flat-corner unit tests in `surface/surface/p7.rs` run on the default kernel. The goldens test `surface_surface_p7::flat_corner_bits_tests::flat_corners_with_points_keep_every_bit` replays every generated and named `flat` case that asks for the points. For each one it checks that the flags equal those of the same call without the points, and that each flagged corner's point is the surface evaluated at that corner of its natural domain (bit for bit), with the unflagged ones left undefined; a flagged corner whose evaluation fails must be left undefined too, and none of the 13 moved rows has one.
- **Results:** 13 goldens rows of `surface.surface_p7` move: `flat_mask_{1,2,4,8,all}_points_1` and gen0191, gen0796, gen1186, gen1584, gen2327, gen2351, gen2373, gen2405. Each one asks for the points of a surface with at least one flat corner. The flags go from 0 to the surface's mask (1, 2, 4, 8 or 15), and the flagged corners' points go from the undefined marker to the corner positions (upstream fills only the first corner's point, and only when that corner is flagged). The goldens test above covers all 13.
