#### WR-304. `SmMerge::BooleanPostProcess` leaves an operand edge inside one face (a slit) after merging its two faces
- **Severity:** Invalid result (a dead-end edge walked out and back inside one loop; no triangulation follows it)
- **Area:** Boolean
- **Location:** `source/SMLib/src/SmMerge.cpp` (`SmMerge::BooleanPostProcess`, the edge loop at about line 857).
- **What happens:** the boolean's clean-up removes topological edges, but with `bCheckAllEdges` false (as `SmMerge` calls it) it checks only the intersection edges with a mate in the other operand. Removing one merges its two faces. An operand edge that lay between two faces which this way become one then bounds the merged face on both sides: a slit. `SmBrep::RemoveTopologicalEdgesAndVertices`, which checks every edge, removes it.
- **Trigger:** a cylinder r 30, z -6..0, united with a disc r 30, z 0..5, extruded from two half arcs. Both wall halves merge into the cylinder's wall, and the line between them at 180 degrees stays as a slit. The SolidCraft rig cases sweeps/494 and booleans/5197 (a revolved hub with its flange annulus extruded from half arcs) show the same thing.
- **How found:** SolidCraft regression rig on the SMLib fork (tangency-labs/solidcore#1120).
- **Confirmed:** no (read at c9c5979 `source/SMLib/src/SmMerge.cpp:848` and `:872`; reproduced on the SolidCraft fork build: the capi `ops_kernel` hub-and-ring join has volume 12056π (Pappus), the check passes, and only its three seams have one face, four before the fix). The Rust trigger above was not run against any C++ build.
- **Fix:** after each edge removal, queue the merged face's edges that now have it on both sides (one face), if not already queued, and check them by the same `IsTopological` test without the mate filter. `IsTopological` keeps seams.
- **Rust port:** opt-in `Kernel::fixes.boolean_cleanup_removes_slits` (default `false`, upstream behaviour), in `boolean_post_process` in `crates/solidcore/src/boolean/merge/p1.rs`. A queued edge that a later removal deleted is skipped. Test: `crates/solidcore/tests/issue_1120_boolean_slits.rs`. Default off, so no difftest case changes. Related: WR-360 (#746) removes slit loops where solids touch; this is a different path. Fixes tangency-labs/solidcore#1120.
