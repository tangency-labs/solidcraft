#### WR-580. `SmEdgeDefinition::Imprint` makes a second edge beside an edge the face already has along the intersection curve, leaving coincident edges
- **Severity:** Wrong result (an invalid body: coincident edges)
- **Area:** Booleans
- **Location:** `source/SMLib/src/SmProtoTopology.cpp`, `SmEdgeDefinition::Imprint`: the Brep2 branch for a definition whose second source is a face (`eType2 == SM_PC_FACE`), which always copies the curve and calls `MakeEdgeInFace`.
- **What happens:** for every intersection curve on a face of the second body, `Imprint` makes a new edge in that face. Where the curve runs along an edge the face already has, between the same two vertices and within tolerance, the face gets a second edge beside its own. Nothing relates its own edge to the first body, so the merge copies it into the first body's face beside the curve's edge: the result has coincident edges (`SmFace` tests 33 and 34).
- **Trigger:** a bicycle frame's seat tube and top tube (r 16) united as SolidCraft's bench builds them (axes rounded to 1e-6, bases and heights to 1e-3, seams 0.6131 rad round). The top tube's wall cut by the seat's end plane runs within tolerance of the seat's end circle over a short stretch near where the two tubes' walls touch.
- **How found:** reported by SolidCraft (its bench frame; tangency-labs/solidcore#1519). The fork's fix is tangency-labs/smlib@81cd61a ("boolean: an intersection edge along a face's own edge is that edge in the other body"), which is not merged upstream.
- **Confirmed:** yes, on the C++ build: at the default fixes the `boolean.api_brep` fixture `issue_1519_bench_tubes.json` gives the same union and the same level-2 check record on both sides (`checked`: 31 exact values; `measured`: 19 exact and 11 values; CI run 41068103436), and that record reports `SmFace` tests 33 and 34 twice each (`wr580_tube_joint_no_coincident_edges`, default fixes). With the fix (and WR-579's) the union is one manifold solid whose check reports nothing.
- **Rust port:** behaves as upstream by default. With `Kernel::fixes.imprint_reuses_coincident_face_edge`, `ProtoTopologyManager::imprint_edge_definition` first asks the B-rep owner for an edge of the face between the definition's two Brep2 vertices along its curve (`ProtoBrep::face_coincident_edge`, `SmTools::FindCoincidentEdge` over `SmFace::GetEdges` within the larger of the face's and the definition's tolerance) and, when one lies within that tolerance, takes it as the definition's Brep2 edge, as the fork does. `crates/solidcore/tests/wr580_tube_joint_no_coincident_edges.rs` builds the bench tubes as rotated `SmApiCreateCylinder`s (the fork uses its C API's extrude), with WR-579's fix set (the union needs it), and checks that the result has coincident edges without this fix and passes the level-2 check with it.
