Updates: WR-43

#### WR-43 (update, 2026-11-15). `curve_bounded_surface_read_uv_type_and_implicit_outer` is removed

The fix is the default and its flag is gone (tangency-labs/solidcraft#14246, batch surface1). `CurveBoundedSurface::read_from_db` (`surface/curve_bounded_surface.rs`) always reads each UV boundary with the type in that boundary's own header and keeps the implicit-outer flag it reads. Upstream reads the UV boundaries with the last 3D boundary's type (0 when there is none, so every UV boundary then fails with `SM_ERR`), and it builds the surface with the flag `false` whatever the record says. Removed: the field `UpstreamFixes::curve_bounded_surface_read_uv_type_and_implicit_outer`, SolidCraft's preset line, its entries in `fixes.json` and `issue_2260`'s list, the `kernel_with_wr43` test helper and the default-path halves of the module's read tests.

- **Tests:** the read tests in `surface/curve_bounded_surface.rs` run on the default kernel. `read_ascii` now pins `implicit_outer() == true` (its stream says `1` in the implicit-outer line). `read_uv_without_3d_uses_type_zero` becomes `read_uv_without_3d_uses_its_own_type` and pins that the record reads: no 3D boundary, and one 2D UV boundary read with its own B-spline header. The goldens test `surface_curve_bounded_surface::wr43_tests::read_records_come_back_as_written` replays every `read_db` case. A record that reads has the implicit-outer flag that was written. When its UV headers say B-spline curve, each UV boundary is a B-spline with the record's degree, knots and control-point count. When they say line, each UV boundary is a line.
- **Results:** 36 goldens rows of `surface.curve_bounded_surface` move. All are `read_db` cases, and each move follows from the record: (a) a record with no 3D boundaries now reads where upstream failed with 1001; (b) the implicit-outer flag of a record that says `1` now reads back as 1, which adds 1 to the state's block sum; (c) a record whose UV headers say line (14010, the generator's mislabelled-header case) is read as lines or refused, where upstream read the B-spline bodies behind those headers with the 3D type. Under (c) the record length and status change, since the line reader takes the body's numbers as line data and the next header no longer lines up. The goldens test above covers all 36.
