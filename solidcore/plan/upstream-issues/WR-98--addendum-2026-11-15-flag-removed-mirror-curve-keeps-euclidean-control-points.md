Updates: WR-98

#### WR-98 (update, 2026-11-15). `mirror_curve_keeps_euclidean_control_points` is removed; `MirrorCurve` reflects a rational curve

`mirror_curve` (`topology/trimming_tools.rs`) keeps the Euclidean control points `GetCanonical` returns and no longer divides them by their weights a second time. Removed: the field, SolidCraft's preset line, the rig's `fixes.json` entry, the flag-list test entry, and `mirror_rational_default_divides_by_weight_twice`, which pinned upstream's result.

- **Defaults:** SolidCraft's preset had the flag on, so the app's results don't change. `Kernel::default()` changes for rational UV curves only; a non-rational curve (or one whose weights are all equal) is unchanged.
- **Goldens:** `topology.trimming_tools`, 12 cases, none of them a moved stored row: each output is longer than 16 entries and holds the 2D curves' `z = f64::MAX` placeholder, so its stored block sums are infinite and hide the change (found by comparing the full arrays). In 10 of them (`mirror_rational_divides_twice`, `rv_mirror_ellipse_u`, `rv_mirror_ellipse_arc_v`, `rv_mirror_ellipse_inside_out`, `gen0055`, `gen0393`, `gen0581`, `gen0695`, `gen0774`, `gen0829`) the output is the mirrored NURB, and a script over the full arrays checks that the header, every weight and every knot are unchanged and every changed entry is a homogeneous control point coordinate with `new == old * w` (1e-12 relative): upstream's stored homogeneous point was the reflected Euclidean point itself, the corrected one is `w` times it. In `gen0162` (`b_tiny`) and `gen0681` (`b_backwards`) the mirror is a pre-step on `plane_circ.smb` and the changed coordinates scale by `w = 1/sqrt(2)` (`-5 -> -3.5355`, `-10 -> -7.0711`).
- **Tests:** `mirror_rational_middle_point_closed_form` checks the fixture's middle point against the closed form `(2 - sqrt(2)/2, sqrt(2)/2)`; `mirror_rational_keeps_euclidean_control_points` and `mirror_rational_twice_is_the_identity` run on the default kernel; `mirror_non_rational_reflects_control_points` checks closed-form reflections.
