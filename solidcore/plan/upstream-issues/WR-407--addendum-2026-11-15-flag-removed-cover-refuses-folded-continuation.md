Updates: WR-407

#### WR-407 (update, 2026-11-15). `cover_refuses_folded_continuation` is removed

The second half of WR-407 is now the default as well, and its flag is gone (tangency-labs/solidcraft#14246, batch surface1; the first half, `sweep_frame_on_planar_path_normal`, went in batch B43). `Surface::cover_coincident_surface` (`surface/surface/p3.rs`) always refuses a cover that would extend a B-spline-based surface past its natural domain onto a continuation that folds. The test samples a 21 x 21 grid over the domain the merge would use. It refuses when the normal vanishes there, when the evaluation fails, or when the normal turns back (dot product <= 0) between neighbouring samples. Upstream merges onto the continuation. Removed: the field `UpstreamFixes::cover_refuses_folded_continuation`, SolidCraft's preset line, its entries in `fixes.json` and `issue_2260`'s list, the goldens SolidCraft-case name mapping, the test settings in six SolidCraft-profile tests (`issue_1476`, `issue_1818`, `issue_1945_fork_1207_step4`, `issue_1950`, `issue_2020`, `wr650`), and the default-path test `issue_434_default_refuses_the_fold_of_a_planar_sheet` (it duplicated the fixed test on the same input). The SolidCraft fixture `434-two-overlapping-swept-arc-walls` now lists no fixes.

- **Why refusing is right:** the test only adds refusals; it never changes a cover that it lets through. A refusal leaves the two faces apart with the edge between them, which is valid topology for coincident faces. A continuation whose normal turns back between two samples is not one sheet over that domain. Covering onto it drops the other face's points onto the wrong sheet: the merged face then spans the fold, and the face rebuilt on it has UV trims far from its edges. #434 shows the result: UV gaps and the wrong volume. Because the grid is sampled, the test can miss a fold narrower than a grid cell (and then merges as upstream does). It can never refuse a continuation without a witness: two neighbouring samples with reversed normals, or a sample where the normal vanishes or the evaluation fails.
- **Tests:** `issue_434_cover_refuses_a_continuation_that_folds` (`surface/surface/p3.rs`) and `tests/wr_407_swept_arc_walls_join_without_fold.rs` (`wr_407_walls_join_to_the_closed_form_with_the_fix`: the two walls join to the closed-form volume) run on the default kernel. `wr_407_default_join_loses_the_folded_cover` is removed. The goldens test `fixes_are_enabled_by_name` (`goldens/src/solidcraft.rs`) used this flag as its example name. It now uses `delete_vertex_joins_seam_iso_curve` and still checks name lookup.
- **Results:** 7 goldens rows of `surface.surface_p3` move: gen0041, gen1448, gen1514, gen1567, gen2066, gen2303 and gen2376. These are the seven generated cover cases that the 2026-10-26 addendum recorded as differing with the fix on. Each `cover` goes from success (1, with a covered domain and an adjusted domain past the natural one) to failure (0, no adjustment; `max_dist` is the failure's 1e20). A leave-one-out run of the batch attributes all 7 rows to this flag.
