#### WR-529. A full-turn rotational sweep of a profile with a hole keeps the hole's ring as material
- **Severity:** Wrong result (the void counted as solid; SmBrep check "Inner shell is not geometrically inside its containing outerShell")
- **Area:** Sweeps
- **Location:** `source/SMLib/src/SmPrimitiveCreation.cpp`, `SmPrimitiveCreation::CreateRotationalSweep` (def. `:2618`), after the faces are stitched (`StitchAndOrient`); the fork's `sm_NestRevolvedShells` (WR-442), which returns early when the infinite region holds fewer than two shells.
- **What happens:** A whole turn sweeps one face per profile curve, and `StitchAndOrient` orients them. For a profile with a hole, `StitchAndOrient` nests the hole's ring inside the ring around it on its own. The infinite region then holds a single shell, so the nesting step returns before it sets any void flag, and the region inside the inner shell stays material. In the fork's example the volume counts the void as solid: 4712.39 instead of 4549.03 for the ring.
- **Trigger:** a square with a square hole turned a whole turn about an axis outside it.
- **How found:** reported by SolidCraft. The fork's fix is tangency-labs/smlib@38b4212 ("revolve: a whole turn of a holed profile leaves the hole's ring a void"), which is not merged upstream.
- **Confirmed:** no C++ run was made here. The pinned C++ (`3fd5b95`) has no nesting step after the stitch at all, and WR-442 adds one that skips this case.
- **Rust port:** behaves as before by default. With `Kernel::fixes.revolve_holed_profile_void`, which only acts when `revolve_nested_shells_as_cavities` is also set, `nest_closed_shells_as_cavities` (`topology/brep/p6.rs`) handles a B-rep whose infinite region holds fewer than two shells. If there are more than two regions and every shell is a closed face-use shell, it sets the void flags from the nesting (`set_region_is_void_flags_for_nested_solids`), as the fork does. `holed_profile_full_turn_leaves_the_hole_a_void` in `primitive/primitive_creation/p3/sweeps.rs` turns a holed square a whole turn and checks the volume against Pappus and a clean level-2 check.
