#### WR-603. `CalcFilletGeom` starts a trace from a tangent point along the edge's end tangent, which can lie on both offsets
- **Severity:** Wrong result
- **Area:** Blend (fillet solver)
- **Location:** `source/SMLib/src/SmFilletSolver.cpp`, `SmFilletSolver::CalcFilletGeom` (def. `:1495`): the trace start direction `sDir` is `sPVSt[1]`, or `-sPVEn[1]` after the reversal for a tangent last point (`:2071` at 1.0.1), even when the first through point is a tangent point.
- **What happens:** at a tangent point the offset surfaces touch, so their normals' cross product gives no direction and the trace starts along the filleted edge's end tangent. That tangent can be the line along which the two offsets touch to second order (the round/wall curve of a bar's top edge rounded into a cylinder tangent to the bar's side ends along the bar's side). The tangent-point step then finds a point along that line on both offsets within tolerance, takes it for the centre curve, misses the next through point, and the retry runs 266 degrees round the cylinder on the round's continuation: a rail off its face, refused as fillet error 8 (`RailsFitTheirFaces`) at every radius.
- **Trigger:** SolidCraft's test-peg part with a one-face cylinder wall: the bar's front top edge rounded r 1, then the concave bar-top/boss arc rounded r 1 with its tangent chain, which runs on along the round/wall curve to the bar's tangent point. On a half-face wall the bad step left the face's u range and was not taken.
- **How found:** SolidCraft (test-peg part). The fork's fix is tangency-labs/smlib@68fb916, which is not merged upstream.
- **Confirmed:** no C++ run was made of the failure. The Rust port follows the pinned C++ (`3fd5b95`) with the flag off. solidcore's version of the peg (`create_cylinder` boss) reaches the changed branch and builds either way, the volume equal to 1e-8.
- **Rust port:** behaves as upstream by default. With `Kernel::fixes.fillet_trace_from_tangent_point_toward_next`, a trace whose first through point is a tangent point (and that has a next one) starts along the chord from that point to the next on the first offset surface, when the chord is longer than `GetThisApproxTol3d()` (`blend/fillet_solver/p4.rs`, `c3_trace_start`).

  Tests: `trace_from_a_tangent_first_point_starts_toward_the_next_with_the_fix` in `crates/solidcore/src/blend/fillet_solver/p4.rs` (the start direction is the chord with the flag on, the edge's start tangent with it off), and `crates/solidcore/tests/wr603_trace_from_tangent_point.rs` (the peg: the arc round with its chain builds with the same face count and added volume with the flag on and off).
