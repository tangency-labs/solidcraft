Re-sign with your sideloading app before installing. This is a test port, not an official upstream iOS release. The desktop layout works best on iPad or in landscape.

Open files with the native Files picker. Save and export to Files → On My iPhone/iPad → SolidCraft. Pinch to zoom, two-finger drag to pan; use the navigation toolbar for orbit.

Desktop-only integrations, external slicers and local agent subprocesses are not supported on iOS.

Package and unsigned status checked. SolidCraft has not yet been tested on a physical device.
