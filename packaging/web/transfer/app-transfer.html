Save your SolidCraft designs as files

This page is at the old address of the SolidCraft web app. It lists the designs this browser keeps for that address, so you can save each one as a file and open it at app.solidcraft.io with File > Open. Nothing here is sent anywhere, and nothing at the old address is changed or deleted.
